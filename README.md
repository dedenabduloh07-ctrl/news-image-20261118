Sum up 18 November 2026's world news in one image. A Python program draws a
newspaper front page: the Shenzhen summit (Xi and Putin meet, Trump lands ahead
of Thursday's first three-way talks), the US–Iran strikes across the Gulf, the
Kerch Bridge road arch collapsing into the strait, and the warning that the
Gaza ceasefire may collapse — plus the day's other news in an ALSO strip.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes one 1024×1024 PNG to `out/entry.png`. It needs no network
and is deterministic: two runs write the same bytes.
